# HVAC FaultSense — Experiments Registry & Artifacts

## 1. Overview

This directory preserves serialized machine learning pipeline artifacts, hyperparameter configurations, and evaluation runs generated by `src/hvac_faultsense/pipeline.py`.

## 2. Serialized Artifacts

- `trained_pipeline.pkl`: Serialized Python dictionary containing:
  - `scaler`: Custom `StandardScalerScratch` fitted strictly on training data ($z = (x - \mu) / \sigma$).
  - `feature_cols`: List of 29 physical and engineered predictor features.
  - `classes`: Array of verified fault labels (`CondenserFouling`, `EvaporatorFouling`, `FaultFree`, `LiquidLineRestriction`, `RefrigerantOvercharge`, `RefrigerantUndercharge`, `SuctionLineRestriction`).
  - `ols_scratch`: Trained `LinearRegressionScratch` model object.
  - `ridge_scratch`: Trained `RidgeRegressionScratch` model object.
  - `pca_scratch`: Trained `PCAScratch` model object ($k=2$).
  - `kmeans_scratch`: Trained `KMeansScratch` model object ($K=4$).
  - `gmm_scratch`: Trained `GaussianMixtureScratch` model object ($K=4$).
  - `hmm_scratch`: Trained `DiscreteHMMViterbiScratch` model object.
  - `cart_scratch`: Trained `DecisionTreeClassifierScratch` model object.
  - `adaboost_scratch`: Trained `AdaBoostClassifierScratch` ensemble model object.

## 3. Reproducibility Configuration

Experiments are configured via `configs/experiments.yaml` and initialized with random seed `42`.
Execution is leakage-safe: chronological split (75% train, 25% test) enforced across all 25 scenario series.
